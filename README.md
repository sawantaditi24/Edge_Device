# Object Detection on Raspberry Pi
This repository contains a project for object detection on a Raspberry Pi, leveraging Python and relevant libraries to perform real-time object detection. 
Object - detection happens in 2 ways here:
 1. A more general way of detecting changes in frame where user is not bound by a list of objects.
 2. A limited set of objects from which user can decide to identify the object.

## About
This project demonstrates implementation object detection on a Raspberry Pi, designed for practical applications in commercial projects.

## Features
- Easy setup and installation
- Real-time object detection
- Ability to perform detection on a limited and general set of objects providing greater flexibility.

## Usage
Upon receiving the raspberry pi kit:
1. Plug the Raspbery pi to power-supply.
2. Configure the SD-card with the wi-fi credentials.
3. Place the SD-card in raspberry-pi.
4. Visit the home page of the website.
5. Choose your way of object detection and see the frames being captured.

## Dependencies
- Python 3.x
- PiCamera2
- OpenCV Python
- NumPy
